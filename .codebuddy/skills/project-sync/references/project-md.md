# PROJECT.md 模板与规范

项目状态权威源，位于项目仓库根。开工时首先读取；每次"上传 Git"自动追加进展；ima《X-项目主页》为其镜像（人类可读版，冷启动入口）。

## 模板

# 项目：X

## 基本信息
- 阶段：（一句话，如"自动键功能开发中"）
- 远端：github/gitee + repo 地址
- 开始日期：YYYY-MM-DD

## 待办
- [ ] 任务描述（进行中标注：分支 feat/xxx）
- [ ] …

## 最近进展（自动追加，保留最近 10 条）
- YYYY-MM-DD [设备标识] 一行摘要（分支 feat/xxx）
- …

## 分支映射
- feat/xxx = 任务中文描述（设备，YYYY-MM-DD 开）

## 待合并
- feat/xxx：N commits，验收要点一句话


## 维护规则

|||
|---|---|
|开启项目|按模板生成骨架|
|每次同步|"最近进展"追加一行（日期+设备+摘要+分支）；超出 10 条裁剪最旧，裁下的归档至 progress-archive.md|
|建/接分支|"分支映射"登记|
|完成提交|分支进"待合并"（含 commit 数与验收要点）|
|授权合并|进展归档一条；"分支映射""待合并"清理对应条目|
|用户手改|允许，AI 下次更新时保留用户内容（只追加不覆盖）|


## 敏感措辞（强制）

投诉材料、POV、竞品相关项目：本文件与 ima 主页、commit message 一律中性措辞（"合规调研""数据整理"级），敏感细节只存在于文件本体（私有仓/私有知识库），绝不写入进展摘要、待办、分支映射的描述文字。

## 设备标识

各设备在 projects.yaml 注册 device 字段，默认由安装任务自动获取本机计算机名（hostname，如 SCB-159），无需手填；进展行与索引条目引用之，用于多电脑溯源。
