# MorsePass · 摩尔斯码训练器

网页版摩尔斯码（CW）收发训练器。纯前端实现，支持 PWA 安装离线使用。

**在线使用**：<https://luojun2057.github.io/morsepass/>

## 功能

| 页面 | 说明 |
| --- | --- |
| 发报训练 | 电键（模拟鼠标点击）/ 键盘 / 触屏发报，实时解码、时间线回显、整场统计报告；自由发报与对照文章发报双模式，对照模式支持按组验证（呼号/通联/数字组全等配对，文章模糊匹配容忍中间错漏并高亮大片对上内容）；练习时素材与发报状态左右分栏同屏，支持一键全屏 |
| 听抄练习 | 播放摩尔斯码凭听抄写，逐字符实时比对（正确/错字/漏抄/多余） |
| 跟发练习 | 5 秒倒计时后播放原文，同时同步跟发，实时评分 |
| Koch 课程 | LCWO 字符序循序渐进学习，≥90% 过关解锁下一字符；支持中途结束评分或放弃本轮 |
| 挑战 | 听选 Quiz（播放→四选一）与 Echo 回发（Morserino 风格：播放→复述→自动评分） |
| 工具 | 码表互转（文本↔摩尔斯双向实时）与 WAV 导出（16bit PCM，采样率可选） |
| 统计 | 历史记录、速度/正确率趋势、弱项字符分析与针对加练 |

### 核心特性

- **全局发报**：练习会话内按住鼠标任意位置即可发报（电键转接器输出鼠标点击场景，光标位置不限），控件点击不受影响
- **PARIS 标准 + Farnsworth 时序**：字符速度与有效速度独立可调
- **固定时间线**：Canvas 渲染最近 10 秒符号（绿=节奏在容差内 / 红=超差），永不撑高页面
- **低延迟音频**：常驻振荡器 + 梯形包络调度（5ms 起音 / 6ms 消音，无咔嗒声），杜绝按键起音延迟；内置延迟诊断
- **双正确率**：整场累计 + 近 10 符滑动窗
- **素材生成器**：字符组 / 4 字一组数字组（组宽可调）/ 常用单词 / 英文文章 / 呼号（含中国前缀 BA·BD·BG·BH·BJ·BS）/ Q 码缩写 / QSO 通联模板（CQ 呼叫、信号报告、致谢结束等）
- **按组验证**：对照发报按词对齐——呼号/通联/数字组全等配对，英文文章按相似度模糊配对、容忍中间错漏，连续对上的大片内容高亮显示
- **QRM 噪声 + QSB 衰落**：可调白噪声干扰与信号衰落，模拟真实信道
- **码表互转**：文本 ↔ 摩尔斯双向实时转换（兼容 ·•— 等常见点划写法）
- **WAV 导出**：把任意素材渲染成 WAV 音频文件（与实时播放相同的包络，无爆音），供训练机/电台使用
- **PWA**：可安装、离线使用

## 本地开发

```bash
npm install
npm run dev       # 开发服务器
npm test          # Vitest 单测（core 全模块 118 用例）
npm run build     # vue-tsc 类型检查 + 生产构建（PWA）
npm run e2e       # Playwright E2E（需先安装浏览器：npx playwright install chromium）
```

## 部署

推送到 `main` 分支后 GitHub Actions 自动构建并部署到 Pages（`.github/workflows/deploy.yml`）。

应用按仓库名假设部署在 `/morsepass/` 子路径；若仓库名不同或部署到根路径，构建时设置环境变量 `MP_BASE` 覆盖，无需改代码。

## 技术栈

Vue 3 + TypeScript + Vite + Vue Router（hash 模式）；无 UI 组件库，手写浅色主题；vite-plugin-pwa。

## 电键接入

硬件电键经转接器输出为鼠标左键/右键点击时：

1. 「电键输入」选择对应鼠标键
2. 点击「开始练习」
3. 按住鼠标任意位置发报：短按为点、长按为划（分类边界 2·Td）

触点抖动由解码器自动合并（5ms 去抖窗口），页面失焦自动抬起防粘键。
